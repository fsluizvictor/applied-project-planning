# Decision Log

> Append one entry per significant decision. Do not delete past entries.  
> Store this file at `deliverables/phase-N/decision-log.md` or keep a running log at `deliverables/decision-log.md`.

---

## Entry Template

Copy the block below and append it at the bottom of this file for each new decision.

```
---

### Decision [sequential number] — [YYYY-MM-DD]

**Phase:** [N — Name]  
**Agent / Author:** [Name]  
**Decision:** [One-sentence statement of what was decided]  
**Rationale:** [Why this option was chosen]  
**Alternatives considered:**
- Option A: [description] — rejected because [reason]
- Option B: [description] — rejected because [reason]

**Impact on deliverables:** [Which files are affected by this decision]  
**Reversibility:** [Easy / Hard / Irreversible — and what would be needed to reverse it]
```
