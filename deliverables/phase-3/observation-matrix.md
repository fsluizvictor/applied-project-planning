# Matriz de Observação — Fase 3: Persona, Empatia e Observação

**Projeto:** Desafio e Solução — Simulador de Conversação em Inglês com IA
**Agente responsável:** Persona & Empathy Specialist
**Data:** 25 de outubro de 2026
**Versão:** 1.0

> **Nota metodológica:** Esta matriz é construída exclusivamente a partir de fontes secundárias já catalogadas na Fase 2 (`deliverables/phase-2/context-report.md`). Nenhuma observação direta, entrevista ou questionário primário foi realizado. A coluna "Resultado" registra o que a fonte documenta — não dados coletados por este projeto. A coluna "Status" indica se a questão está respondida pela evidência disponível, parcialmente respondida ou em aberto para validação futura.

## Estrutura da Matriz

| Coluna | Descrição |
|--------|-----------|

|-------|----------|
| **Questão de Pesquisa** | Quais são as principais barreiras que impedem aprendizes de EFL de falar inglês? |

| **Fonte / Evidência** | `[FONTE-SECUNDÁRIA]` DEWITT; MOOSAVI, 2022 |
| **Resultado** | Problemas psicológicos (ansiedade, medo de errar, baixa autoconfiança) são a barreira mais frequente, seguidos por problemas ambientais (métodos de ensino, falta de prática) e linguísticos (vocabulário, pronúncia). |

| **Próxima Ação** | Pesquisa primária com usuários brasileiros para confirmar a hierarquia de barreiras neste contexto específico (QV-01) |

### Tema 4 — Eficácia de Chatbots de IA para Prática de Fala

| Campo | Conteúdo |
|-------|----------|
| **Questão de Pesquisa** | Chatbots de IA melhoram o desempenho oral de aprendizes de inglês em comparação a condições sem chatbot? |
| **Comportamento / Tema Observado** | Desempenho em fala de grupo experimental (IA) versus grupo controle |
| **Método de Coleta** | Meta-análise de 70 tamanhos de efeito extraídos de 28 estudos |
| **Fonte / Evidência** | `[FONTE-SECUNDÁRIA]` WANG et al., 2024 |
| **Resultado** | Efeito positivo geral: g = 0,484. Eficácia varia conforme nível educacional, proficiência, design de interface e capacidade de interação do sistema. |
| **Status** | ✅ Respondido para populações estudadas — **não há estudo específico com público brasileiro** `[LACUNA DE EVIDÊNCIA — B-04]` |
| **Próxima Ação** | Tratar como base de plausibilidade; não extrapolar como fato estabelecido para o contexto brasileiro |

| Campo | Conteúdo |
|-------|----------|
| **Questão de Pesquisa** | Um chatbot de IA específico melhora fluência, coerência, pronúncia e WTC em comparação à interação humana face a face? |
| **Comportamento / Tema Observado** | Desempenho pós-teste em múltiplas dimensões da fala |
| **Método de Coleta** | Experimento controlado com 65 aprendizes de EFL (33 grupo IA, 32 grupo controle) |

### Tema 5 — Limitações Técnicas e Pedagógicas de Chatbots para Fala

| Campo | Conteúdo |
|-------|----------|
| **Questão de Pesquisa** | Sistemas de reconhecimento de fala têm desempenho diferenciado para falantes não nativos? |
| **Comportamento / Tema Observado** | Taxa de erro de palavras (WER) para fala em segunda língua |
| **Método de Coleta** | Estudo experimental com sistema de ASR + LLM |
| **Fonte / Evidência** | `[FONTE-SECUNDÁRIA]` VERHELST; BELPAEME, 2025 |

| **Status** | ✅ Respondido — limitação técnica documentada; aplicabilidade ao inglês como L2 é `[INFERÊNCIA]` |
| **Próxima Ação** | Considerar como restrição de design na Fase 6; testar com sotaque brasileiro em protótipo |
